# 🌦️ Weather Analysis Dashboard | Power BI Project

## 📌 Project Overview
This project is an interactive Weather Analysis Dashboard created in Power BI to analyze weather patterns and climate trends using data visualization techniques.

The dashboard provides insights related to:
- Temperature Analysis
- Humidity Tracking
- Rainfall Analysis
- Seasonal Trends
- City-wise Weather Comparison
- Climate Insights

---

## 🛠️ Tools & Technologies Used
- Power BI
- DAX
- Excel / CSV
- Power Query
- Data Visualization

- `POWER BI 3.pbix` → Main Dashboard File
